# 暗算迷宮

## 概要
本ゲームは、openFrameworks(C++)を用いて制作した、迷路探索と暗算を組み合わせた学習ゲームです。

プレイヤーは敵キャラクターと競争しながら暗算問題を解き、アイテムを活用しつつゴールを目指します。

## 製作情報
- 製作期間:約2か月
- 製作人数:1人
- 開発環境:macOS, Xcode
- 使用言語:C++
- ライブラリ:openFrameworks

## ゲームの流れ
1. タイトル画面
2. 練習またはゲーム開始
3. 難易度(学年)を選択
4. 遊びたいステージを選択
5. 問題を解き、正解するとランダムでアイテムがもらえるが、間違えるとランダムでペナルティが発生
6. マップに配置されている宝箱に触れるとランダムでアイテムがもらえる。
7. アイテムを活用しながらゴールを目指す。
8. 敵より先にゴールにつけばクリア、敵が先にゴールについたらゲームオーバー。
9. もう一度同じステージの難易度で遊ぶか、ステージ選択に戻るか、問題の難易度選択に戻るか、タイトルに戻るか選択する。

## 操作方法

上下左右キー:移動
1キー:赤ボタン
2キー:青ボタン
3キー:黄色ボタン
4キー:緑ボタン
Enterキー:白ボタン

この配置の理由は、研究室で手作りされたコントローラーのキーボード配置がこのようになっているためです。
